# ADR-0059: 新しい版の知らせは、どの画面でもいちばん上の帯にする

- 日付: 2026-11-09
- 状態: 承認（ADR-0045 の知らせを出す場所「画面の下」を置き換える。雛形 fastapitemplate の ADR-0106 の写し・task #938）

## 文脈

新しい版が配られると「新しい版があります。［再読み込み］」を出す（ADR-0045）。これまでは画面の下の中央に
浮かべていたが、本文やトーストに紛れて目立たなかった。雛形 fastapitemplate で、持ち主の求め（「一番上にして
目立つようにしたい。ポップアップでなくヘッダーに出したい」）に応えていちばん上の帯へ変え（雛形の ADR-0106）、
持ち主が本番で試して「他にも展開したい」となった。

ヘッダーはサインイン後の外枠にしか無く、ログイン画面・SSO の戻り・表示端末の画面（`/display`）には無い。

## 決定

1. 知らせは**画面のいちばん上に、横幅いっぱいの帯で**出す。アクセント色の地にし、ボタンは色を反転させる。
   押されるまで消さない（ADR-0045 のまま）。
2. 帯は `main.tsx` で画面（`<App />`）より前に置き、**どの画面にも**出す。`position: sticky; top: 0` で、
   下へ送っても上に残す。切り欠きのある端末では、上の安全域の分だけ帯の中を広げる。
3. サインイン後の画面では、ヘッダーが帯の**真下に**貼り付く。帯は自分の高さを `<html>` の CSS 変数
   `--update-bar-height` で渡し（狭い画面で折り返すと高さが変わるので `ResizeObserver` で見張る）、
   `.header` は `top: var(--update-bar-height, 0px)` に貼り付く。帯が消えたら変数を外す。
4. 重ね順はヘッダー（30）＜帯（35）＜狭い画面の幕（40）・引き出し（50）。引き出しが開いている間は引き出しだけを
   操作させるため。

## 理由

- **ヘッダーの中に入れない。** ヘッダーの無い画面で出なくなる。帯をヘッダーの上の別の段にすれば、
  ヘッダーのある画面ではヘッダーと一体に見え、無い画面でも同じ位置に出る。
- **固定（`position: fixed`）にしない。** 本文の上に重なり、ヘッダーや本文の先頭を隠す。sticky なら場所を取るので
  何も隠さない。
- **ヘッダーの位置を変数で渡す。** 帯はルーターの外（どの画面でも出すため）、ヘッダーは画面の中にあり、
  同じ箱に入れて一緒に貼り付けられない。
- 雛形と同じ形・同じ名前（`update-bar`・`--update-bar-height`）にしておけば、雛形の変更を取り込みやすい。

## 影響

- ⚠ **上に貼り付く要素（`position: sticky; top: …`）を足すときは、`top` に `var(--update-bar-height, 0px)` を足す。**
  足さないと、知らせが出ている間その要素が帯の下に潜る。2026-11-09 時点で上に貼り付くのはヘッダーだけ。
