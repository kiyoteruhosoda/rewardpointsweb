# ADR-0056: 通信先の URL と鍵のファイルの場所は環境変数だけで決める

- 日付: 2026-10-30
- 状態: 承認（持ち主が案を承認。task #743）

## 文脈

設定は DB > 環境変数 > 既定値で解決するので、設定を書ける人はサーバーの通信先と鍵のファイルの場所を画面から任意の
値にでき、秘密を載せた通信を宅内や外へ向けられた。宛先の検査は掛けられない。正しい値がクラスタの内側を指す設定が
あり、宅内では assay の公開名が私設のアドレスを返すので、名前を引くと自分の IdP を断ってしまう。
fastapitemplate の ADR-0090 と同じ形にする。

## 決定

1. **通信先の URL と鍵のファイルの場所は環境変数だけで決める**（`ENV_ONLY_SETTINGS`: `OIDC_ISSUER`・`OIDC_PRIVATE_KEY_FILE`）。解決順の例外で、
   DB に値が残っていても読まない。画面には見るだけで出し、保存は 400 `setting_env_only` で断る。
2. **`MAIL_SERVER` は画面に残し、形を確かめる**（`check_host_name`。全世界向けでない IP の直書きと内側にしか無い
   名前は 400 `invalid_destination`）。
3. OIDC の discovery と JWKS は転送を追わない。

## 影響

- ⚠ 環境変数を入れずに DB の値だけで動かしていた設定は、取り込むと空に戻る。DB に残った値は消さない（読まれないだけ）。
